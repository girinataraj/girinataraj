Every image embedded by README.md is an animated GIF or a looping animated SVG. The original PNG remains an authoring source only. Native Markdown prose, links and tables remain readable text because a GitHub profile README is not a scriptable website.

## Rendering and refresh

GitHub's native image renderer plays GIFs and SVG animation; no embedded JavaScript, iframe or external animation service is used. SVG URLs include a motion revision query so cached v2 stills are replaced promptly. The daily Python generator includes motion when rebuilding all three live-data SVGs.

CSS animations use reduced-motion overrides where supported. GIF and SMIL playback is controlled by the viewing browser; the profile does not disable the viewer's controls or preferences. Loops use gentle motion rather than flashing transitions.

## Verification

The authoring checks enumerate every README image, reject still formats, verify continuous SVG motion, and decode multiple GIF frames to ensure distinct pixels and infinite playback. Browser frame comparisons check that actual GIF and SVG rendering changes over time. The ordinary source-data tests still run, and all SVGs are XML-parsed and rasterized before publication to the review branch.
