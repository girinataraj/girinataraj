# Artwork provenance

## Hero

`assets/hero-cinematic.png` was generated with the built-in image-generation tool and copied unchanged into the project. It depicts a fictional developer mascot, not an identity-matched portrait. Reference screenshots informed richness, not the artwork or identity.

The README displays `assets/hero-motion.gif`, a motion composition derived from that source: 48 frames with portrait parallax, particles, HUD elements and typing text. Node.js and Sharp encode the animation; the original PNG is retained as an authoring source and is not displayed in the README. This is animated artwork, not live video or a claim of facial-expression animation.

Final prompt submitted:

> Use case: stylized-concept. Asset type: final cinematic GitHub profile hero banner, ultra-wide 3:1 horizontal composition, high resolution. Create a sophisticated original anime-meets-premium-game-key-art engineering identity for Giri Nataraj. A mature young adult South Asian male fictional developer mascot with medium brown skin, thick naturally swept dark hair, slight stubble, black technical jacket, calm confident expression, three-quarter view facing toward the left, shoulders and upper torso in the rightmost third. This is an original illustrative mascot, not a portrait of a real person and not a copied character. Behind him a precise circular holographic interface, fine cyan circuitry and architectural blueprint layers, a small floating glass code window, sharp electric cyan edge lighting and subtle amber highlights. Background near-black midnight navy #07111e, deep indigo atmospheric gradients, controlled light rays, realistic painted textures, exceptional editorial polish. On the left two-thirds large very crisp typographic title exactly 'GIRI NATARAJ' in two stacked lines, GIRI in cool white and NATARAJ with tasteful cyan-to-electric-blue gradient. Below title place exact smaller words 'FULL-STACK / APPLIED AI'. Top-left tiny technical eyebrow exactly 'DESIGN. BUILD. CONNECT.' Bottom left a fine technical rule, 3 small conceptual line symbols representing interface, database and intelligence. Keep lots of breathing room around typography, typography visually dominant and readable at small size. Right-side portrait well lit, detailed, graceful integrated fade into the left. No company logos, no real skill logos, no fake statistics, no badges, no availability claims, no watermark, no extra text. The composition should feel like an established independent engineer's personal command center: bold, cinematic, authored, technically sophisticated, substantially richer than a stock gradient banner. No childish chibi proportions, no flat emoji art, no messy cyberpunk city, no excessive glow, no purple-pink wash.

## Vector assets and source images

Section dividers, navigation chips, capabilities, all five project covers, console, signal ribbon and contact panel are original looping SVG artwork. Project covers are conceptual diagrams. The expandable QueueLess section uses a looping GIF carousel of four actual development screenshots from `docs/screenshots/react-{customer,staff,owner,display}-1366.png` in that source repository; it is a screenshot tour, not a recording of live interaction.

## Technology icons

Downloaded from the official [Devicon project](https://github.com/devicons/devicon), `master/icons/<technology>/<technology>-original.svg`, on 2026-10-28. License retained at `assets/icons/LICENSE.devicon`. Logos belong to their respective owners and identify the technologies.

## Activity graphics

Generated by `scripts/update_activity.py` from public GitHub metadata and the public profile calendar. No invented activity, ranks or coding scores are used.
